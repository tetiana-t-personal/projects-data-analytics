This activity demonstrates how to enhance a Power BI report by importing and configuring a custom visualization from Microsoft AppSource. The goal is to improve data storytelling by replacing a standard chart with a more expressive visual.

📌 Result
The report now includes a custom Aster Plot visualization, improving clarity and visual impact of sales distribution by country while maintaining a consistent design style across all visuals.

📈 Outcome
This enhancement demonstrates:
How to extend Power BI using AppSource visuals
How custom visuals improve storytelling
How consistent formatting improves report usability and design quality
