The report uses several visualisation techniques to highlight key insights from the data.

The funnel chart is enhanced by highlighting the top 10 selling products by sales amount, allowing users to quickly identify the best-performing products.

The histogram improves clarity by using age bins instead of individual ages, which makes it easier to observe patterns across age groups.
This visualisation also clearly shows a decline in the number of customers across certain age groups.

In addition, the scatter chart groups cities into four performance clusters, helping to identify patterns and compare how different locations perform relative to each other.

Overall, the Top N analysis effectively highlights the best-performing products, providing a concise overview of their success and making it easier for decision-makers to focus on the most important data.
