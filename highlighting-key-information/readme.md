The report includes a table detailing each category, showing the annual target and actual sales for each one.
For better readability, conditional formatting has been applied: the highest sales figures are highlighted in a different colour, allowing managers to immediately spot the top-performing categories.

The report also features a column chart, visualising target vs sales by category.
A consistent colour scheme has been applied throughout the report to enhance clarity and visual appeal.

This report enables managers to quickly assess which categories are meeting their targets and which are falling behind, allowing them to focus on both top-performing and underperforming segments.
